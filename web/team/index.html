FAQ

Deployment and product questions

Is Team just a hosted desktop app?

No. Desktop is standalone and local-only, with no shared daemon. Team is commercial server software that stays running from a trusted network vantage point and serves authorized browsers, API clients, and MCP clients.

What exactly is retained?

The daemon keeps bounded signal history in memory for incident context. It is not durable storage and resets on every restart. JSONL audit records are written only when you configure --audit-log.

Can API, MCP, or chat execute commands?

No. MCP and chat are read-only. The API does not expose an arbitrary shell. Any operator action is a server-owned named action, configured in advance and bounded by server-side controls.

Where should the daemon run?

On a least-privileged host that can reach only the systems and checks it needs. Put TLS and your normal network controls in front, use restricted SSH principals, and issue access only to authorized teammates and clients.

What does white-glove install and mapping include?

Starting at $3,000 one-time, we help deploy the daemon, establish least-privilege access, configure TLS and authentication, and map the first agreed production scope. Final scope and price depend on the environment.

Is Team Daemon MIT-licensed?

No. Reticle Desktop is free and MIT-licensed. Team Daemon is commercial software provided under a paid subscription.
